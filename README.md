# NSH WordPress Membership Plugins

This repository contains two independent WordPress plugins for NSH membership verification demos.

## Plugins

### NSH Membership Verification Demo

Folder: [`nsh-membership-verification/`](./nsh-membership-verification/)

An event-based demo with an organizer event dashboard, tokenized participant links, simulated payment/trial selection, event verification codes, and per-event participant lists.

### NSH Membership Simple Verification

Folder: [`nsh_membership_simple_verification/`](./nsh_membership_simple_verification/)

An email-first flow with paid/trial/unpaid status handling, sign-up and payment-demo steps, trial limits, and an organizer code-validation page. This plugin creates the pages it needs when activated.

## Install

For either plugin, zip its plugin folder and upload the ZIP under **WordPress Admin → Plugins → Add New Plugin → Upload Plugin**, then activate it. Each plugin folder contains its own README with setup details.

The payment options in both plugins are demonstrations only. They do not process real payments or independently confirm membership eligibility.
